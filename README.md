# Minecraft Mod: Monochrome Manga Skin

Monochrome Manga Skin is a Fabric Minecraft mod and 64x64 player skin resource featuring a monochromatic anime and manga style with grayscale shading, dark layered hair, glasses, a black swimsuit, necklace details, a spider tattoo, and pixel based outlines.

## Install

1. Install Minecraft 26.3 with Fabric Loader 0.20.1 or newer.
2. Install Fabric API.
3. Install Java 25 or newer.
4. Copy `monochrome_manga_skin-1.0.0.jar` into the Minecraft `mods` folder.
5. For use as a player skin, convert `src/main/resources/assets/monochrome_manga_skin/textures/monochrome_manga_skin.svg` to a 64x64 PNG with an image editor or vector conversion tool.
6. Upload the PNG through the Minecraft launcher or your preferred skin manager.

The mod does not add gameplay mechanics, items, entities, commands, or blocks. It packages the skin resource and its editable SVG artwork.

## Use

1. Launch Minecraft with Fabric and the mod installed to verify that the mod loads.
2. Open the included SVG source file in a vector graphics editor if you want to adjust the colors or pixel artwork.
3. Export the artwork as a 64x64 PNG.
4. Apply the exported PNG as your Minecraft player skin.
5. Keep the mod in the `mods` folder when playing with the Fabric profile.
